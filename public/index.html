CreativeID Directory

Creative personas published by the people themselves, to AT Protocol, Solid Pods or their own websites. This directory only reads what they published, and anyone can run another.

Personas

    Choose a persona to see their works, who they've worked with, and where two people's accounts match.

    Add a persona to this directory

    Paste an at:// link, a DID, an @handle, a Solid resource, a link to a creativeid.jsonld file, or just a domain (its /.well-known/creativeid.jsonld is read). The directory fetches it and keeps a copy; the original stays where it is.

    Use the API

    Everything on this page comes from a JSON API that any site can call.

    • /v1/personas?q=&discipline=&based=&protocol=
    • /v1/personas/:id (index id, DID, handle, URL or domain), with /works, /connections, /loops
    • /v1/disciplines
    • /v1/stats
    • POST /v1/index with { "uri": "…" } to add or refresh a persona
