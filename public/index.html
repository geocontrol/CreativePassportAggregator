Developer API Reference

  • GET /v1/artists?q=<term>&protocol=<atproto|solid|static> Full-text search across names, bios, handles, and DIDs.
  • GET /v1/artists/:identifier Lookup by Aggregator ID, DID (did:plc:...), handle, or URI. Add ?view=jsonld for pure Linked Data.
  • POST /v1/index Ping-on-publish webhook to fetch & index a remote URI.
  • POST /v1/jetstream/event Ingest filtered ATProto Jetstream commit events.
